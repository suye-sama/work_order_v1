================================================================================
    飞书机器人接入操作指南
    售后工单系统 — 将 AI 能力嵌入飞书工作台
================================================================================

【概述】

  本指南将带你将售后工单系统的核心 AI 能力（日志解析、相似检索），
  通过飞书机器人嵌入飞书工作台，实现移动化智能辅助。

  支持场景：
    · 场景一：工程师在飞书群/单聊发送终端日志 → 机器人自动解析生成工单草稿
    · 场景二：工程师输入「搜索：关键词」→ 机器人从知识库召回 Top-5 历史案例

  核心策略：不重构现有 Agent 逻辑，在 FastAPI 主服务层新增飞书适配层，
              将 REST API 能力包装为飞书可调用的技能。

  预计耗时：约 2 小时（含飞书后台配置 + 内网穿透 + 联调测试）


================================================================================
第一步：确认系统可正常运行
================================================================================

  确保以下服务能正常启动（本地开发使用 SQLite，无需 Redis/PostgreSQL）：

    服务                  端口    启动命令
    ─────────────────────────────────────────────────────────
    Flask Agent 微服务     5000    cd agent && python -m flask --app app.main run --host 127.0.0.1 --port 5000
    FastAPI 主服务         8000    cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

  验证：
    · 浏览器访问 http://127.0.0.1:8000/docs → 应显示 Swagger 文档
    · 浏览器访问 http://127.0.0.1:5000/agent/log/parse → 应返回 400/405（非 GET 方法，正常）


================================================================================
第二步：安装内网穿透工具（cpolar）
================================================================================

  飞书回调需要一个公网 URL，本地开发需使用内网穿透工具。

  2.1 下载 cpolar

    官网：https://www.cpolar.com/download

    Windows 用户选择：cpolar-stable-windows-amd64.zip
    macOS 用户选择：cpolar-stable-darwin-amd64.zip

  2.2 解压到本地目录

    例如：E:\Tools\cpolar\

  2.3 启动内网穿透

    打开终端，进入 cpolar 目录，执行：

        cpolar http 8000

    启动成功后会显示：

        Forwarding: https://abc123.r27.cpolar.top -> http://localhost:8000

    记下这个 HTTPS 地址，后面飞书配置要用。

  ⚠️ 注意：
    · 免费版 cpolar 每次重启 URL 会变化，届时需同步更新飞书后台
    · cpolar 必须保持运行，飞书回调才能到达你的本地服务

  备选方案（如已有其他工具）：
    · ngrok：https://ngrok.com/download → ngrok http 8000
    · frp：自行配置 frpc.ini，将本地 8000 端口映射到公网服务器


================================================================================
第三步：飞书开发者后台配置
================================================================================

  3.1 创建应用

    1. 访问 https://open.feishu.cn 登录飞书开发者后台
    2. 点击「创建企业自建应用」
    3. 填写：
       应用名称：售后工单智能助手
       应用描述：基于AI大模型的售后工单辅助系统，支持终端日志智能解析、
                历史案例相似检索，帮助工程师快速生成标准化工单
    4. 点击创建

  3.2 获取凭证

    左侧「凭证与基础信息」→ 复制以下两项（后续配置 .env 要用）：
      · App ID：       cli_xxxxxxxxxxxxxxxx
      · App Secret：   xxxxxxxxxxxxxxxxxxxxxxxx

  3.3 配置机器人

    左侧「机器人」→ 开启机器人能力 → 填写：
      机器人名称：售后助手
      机器人描述：售后工单智能辅助机器人。向我发送终端报错日志，自动解析生成
                  工单草稿；输入「搜索+关键词」，帮你查找历史相似案例。
      保存。

  3.4 配置事件订阅

    左侧「事件订阅」→ 填入请求网址：

        https://你的cpolar地址/feishu/event

    例如：https://abc123.r27.cpolar.top/feishu/event

    添加事件：搜索 im.message.receive_v1 → 勾选 → 保存

    ⚠️ 保存前确保 FastAPI 正在运行，否则 URL 验证会失败。

  3.5 配置权限

    左侧「权限管理」→ 搜索并开通：
      · im:message            — 获取消息内容
      · im:message:send_as_bot — 以机器人身份发送消息
      开通后保存。

  3.6 发布应用

    左侧「版本管理与发布」→ 创建版本（如 1.0.0）→ 填写更新说明 → 提交审核
    → 审核通过 → 状态变为「已发布」。

    ⚠️ 必须发布后，机器人才能接收消息。


================================================================================
第四步：配置环境变量
================================================================================

  编辑项目根目录的 .env 文件，确保以下飞书配置项存在（将占位符替换为实际值）：

    # ===========================================
    # 飞书配置
    # ===========================================
    FEISHU_APP_ID=cli_xxxxxxxxxxxxxxxx          # 步骤 3.2 获取的 App ID
    FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxx     # 步骤 3.2 获取的 App Secret
    FEISHU_VERIFICATION_TOKEN=                  # 开发环境留空即可
    FEISHU_ENCRYPT_KEY=                         # 开发环境留空即可
    FEISHU_BOT_NAME=售后助手

  ⚠️ 不需要 Redis — 限流和 Token 缓存使用内存方案，本地开发可直接使用。

第五步：安装依赖
================================================================================

  确认以下 Python 包已安装：

    pip install lark-oapi        # 飞书开放平台 SDK
    pip install python-dotenv    # .env 环境变量加载
    pip install httpx            # 异步 HTTP 客户端

  验证安装：

    python -c "import lark_oapi; import dotenv; import httpx; print('OK')"


================================================================================
第六步：启动全部服务
================================================================================

  需要 3 个终端窗口，按顺序启动：

    终端 1 — Flask Agent 微服务（端口 5000）：
        cd agent
        python -m flask --app app.main run --host 127.0.0.1 --port 5000

    终端 2 — FastAPI 主服务（端口 8000）：
        cd backend
        python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

    终端 3 — cpolar 内网穿透：
        cd E:\Tools\cpolar     # 替换为你的 cpolar 目录
        cpolar http 8000

  全部启动后，确认 cpolar 终端显示的公网 URL 与飞书后台配置一致。

第七步：联调测试
================================================================================

  7.1 单聊测试

    1. 打开飞书客户端
    2. 左上角搜索「售后助手」→ 进入单聊
    3. 发一条消息测试：

       消息内容                         预期回复
       ──────────────────────────────────────────────────────
       搜索：Nginx 502                  📚 相关历史案例 卡片
       systemctl status nginx          🔍 日志分析结果 卡片

  7.2 群聊测试

    1. 创建一个测试群
    2. 群设置 → 群机器人 → 添加「售后助手」
    3. 发消息时注意 @售后助手：

       @售后助手 搜索：Nginx

  7.3 查看日志

    FastAPI 终端会打印飞书事件处理日志，便于排查问题。


================================================================================
常见问题排查
================================================================================

  Q: 飞书保存事件订阅时提示「Challenge code没有返回」
  A: 确认 FastAPI 正在运行（端口 8000），且 cpolar 已启动。浏览器访问
     https://你的cpolar地址/feishu/event 应返回 {"status":"feishu event endpoint ready"}

  Q: 发消息给机器人没有反应
  A: 1) 确认应用已「发布」而非仅「创建版本」
     2) 确认权限管理中已开通 im:message 和 im:message:send_as_bot
     3) 群聊中必须 @机器人 才能触发

  Q: 机器人回复「获取 tenant_access_token 失败」
  A: 检查 .env 中 FEISHU_APP_ID 和 FEISHU_APP_SECRET 是否正确

  Q: 机器人回复「权限不足」
  A: 确认权限管理中已开通 im:message:send_as_bot → 重新发布版本

  Q: cpolar URL 变了怎么办
  A: 同步更新飞书后台两处（事件订阅 + 回调配置）的请求网址

  Q: 搜索结果卡片显示「原因：暂无」
  A: 知识库需要提前导入数据。通过 Web 端工单详情页「提取知识」按钮入库。

飞书集成模块说明
================================================================================

    文件                            作用
    ─────────────────────────────────────────────────────────────
    backend/app/integrations/
      feishu_client.py              SDK 封装：Token 缓存、文本/卡片消息发送
      feishu_cards.py              卡片模板：解析结果/检索结果/错误提示
      feishu_auth.py               事件解密工具（加密模式预留）
    backend/app/api/
      feishu_routes.py             /feishu/event 回调路由 + URL验证 + 意图分发
    backend/app/tasks/
      agent_tasks.py               异步任务：调 Agent 接口 → 构建卡片 → 推送回复

  数据流：
    飞书用户发消息 → 飞书平台 POST → cpolar → FastAPI /feishu/event
    → 意图识别 → 异步调 Flask Agent → 构建卡片 → 飞书 API 推送回复
